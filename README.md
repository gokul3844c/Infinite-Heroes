# 🦸 Hero Rush

A high-speed **3D Endless Runner Game** where players choose a superhero-inspired character, dodge obstacles, and survive as long as possible to achieve the highest running score.

> **Status:** 🚧 Active Development

---

# 🎮 Gameplay

Hero Rush is an action-packed endless runner where your objective is to run as far as possible while avoiding randomly generated obstacles.

The longer you survive, the faster the game becomes, increasing the challenge.

There are **no coins, shops, or power-ups**—only your skill and your running score matter.

# 🚧 Obstacles

Examples include:

* Cars
* Trucks
* Buses
* Concrete Barriers
* Construction Blocks
* Road Cones
* Broken Roads
* Fire Barriers

Obstacle speed and spawn rate increase as the game progresses.

---

# 📊 Scoring System

The game uses a **distance-based scoring system**.

* Running Score starts at **0**.
* Score increases continuously while the player is running.
* Score stops immediately after a collision.
* Highest score is saved automatically on the device.
